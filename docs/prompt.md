# 角色
你是资深全栈工程师兼教育产品设计师，熟悉 IB 课程体系（MYP 初中、DP 高中）和家校沟通场景。

# 任务
设计并实现「家校联络平台」MVP：老师布置的任务、学生完成情况、家长反馈都能及时呈现，方便家校联络，持续跟踪孩子成长。学校以 IB 国际课程为主，覆盖初中（MYP）和高中（DP）。

# 用户与权限
- 老师：管理任教班级与学生，布置任务（作业、项目、测验），按 IB 标准打分和写评语，查看家长反馈。
- 学生：查看任务，提交作业或标记完成，写反思，登记 CAS 经历和 EE 进度。
- 家长：只能看自己孩子的任务、完成状态、成绩、评语和 IB 进度，可给老师留言。
- CAS 协调员 / EE 导师：审核 CAS 记录，跟进所带学生的 EE 里程碑。
- 管理员：配置学年、年级、班级、学科，批量导入账号。
数据严格隔离：家长只看自己孩子，老师只看任教班级，导师只看所带学生。

# 核心功能（第一期全部交付）
1. 任务：标题、学科、截止日期、说明、附件、关联的 IB 评估标准。
2. 完成跟踪：未开始 / 进行中 / 已提交 / 已批改 / 逾期；按学生看时间线和完成率。
3. 反馈：老师评语、家长留言、学生反思，按任务组成对话串，带未读标记。
4. 通知：新任务、临近截止、逾期、新评语、新反馈、EE/CAS 截止提醒。第一期只发邮件（重要事件即时 + 每周汇总），家长可选频率；站内未读提醒同步显示。
5. 看板：老师看全班完成率、逾期名单、各 Criteria 分布；家长看孩子本周任务、近期评语、IB 进度。
6. IB 评估标准：MYP 各学科 Criteria A–D（1–8 级）打分与评语、学期/学年汇总和成长曲线；DP 各科 1–7 分及内部评估（IA）进度。
7. CAS 记录（DP）：登记 Creativity / Activity / Service 经历、反思和证据；协调员审核；跟踪 7 项学习成果覆盖情况和 CAS 项目进度。
8. Extended Essay 进度：选题、导师分配、三次反思会（RPPF）、初稿、终稿等里程碑和截止日期；导师评语；逾期提醒发给学生和家长。
9. MYP 个人项目 / 社区项目里程碑跟踪（与 EE 共用里程碑组件）。

# 技术约束
- 后端统一用腾讯云 CloudBase（云开发）：身份认证（邮箱/手机号登录，国内可用）、云数据库、云存储、云函数；用户主要在中国大陆，不使用 Google/Firebase 等国内不可稳定访问的服务。
- 第一期前端：响应式 Web（手机优先，家长主要用手机），中英双语，部署在 CloudBase 静态网站托管。
- 微信小程序：暂未认证，第一期不开发界面，只预留接口——业务逻辑全部放在云函数/HTTP API 里，认证层预留微信登录（openid 绑定账号）入口，通知层抽象成渠道适配器（email 已实现，wechat_subscribe 留空实现），以后小程序可直接复用同一后端。
- 邮件发件地址：dannysuperbot@mail.grokbot.com。通过通知渠道适配器发送；如该地址无法被应用直接调用（如无 SMTP/API），先把待发邮件写入发件队列，由运营 bot 代发，并在文档中写明。
- 数据库安全规则必须按角色和亲子/任教/指导关系校验，上线前审计并写测试。
- 涉及未成年人数据：最少采集，不公开任何页面，关键操作留日志。

# 交付物
1. 数据模型（集合、字段、关系）。
2. 页面清单和主要流程（老师、家长、学生、协调员/导师）。
3. 可运行的代码仓库与 CloudBase 部署地址。
4. 安全规则及测试用例。
5. API 文档（供将来小程序接入）。
6. 演示数据：一个 MYP 班和一个 DP 班，各 5 名学生，含 Criteria 打分、CAS 记录和 EE 里程碑样例。

# 验收标准
- 老师布置任务后 1 分钟内，学生和家长网页可见；邮件通知按设置发出。
- 家长账号无法读取别人孩子的任何数据，有规则测试证明。
- 老师按 Criteria 给 MYP 任务打分后，家长能看到分数、评语，并收到邮件。
- 主要页面在手机浏览器上可用。
- 小程序接入只需新增前端，不改业务后端。
