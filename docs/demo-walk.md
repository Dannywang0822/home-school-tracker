# 静态演示走查

虚构账号，密码都是 `DemoOnly-2026!`。刷新页面会回到初始数据。这不是学校正式系统。

## 学生一 `s1@demo.school.local`

- 「科学实验」：状态是未开始。可以点「开始」，填写内容，选择附件，再提交。
- 「科学草稿」：已经提交过。可以再次提交。看不到草稿分数。
- 「科学测验」：已经批改。只能看已发布的分数和评语。页面上没有「开始」「提交」「标记完成」。

## 学生二 `s2@demo.school.local`

登录后打开「我的任务」，能看到逾期任务。这条任务只布置给了学生二。

## 未同意的学生 `minor@demo.school.local`

登录后停在知情同意。不能打开任务列表。

## 隔离

学生一的任务列表里没有学生二的专属任务，也没有学生三的 DP 物理作业。

## 老师发布，家长查看

1. `t1@demo.school.local` 打开「班级任务」里的「科学实验」，进入「演示学生一」，填写标准 A、B 和总评，点「发布成绩」。
2. `p1@demo.school.local` 打开「成绩」（`/#/p/grades`）和该任务页，能看到已发布的分数和评语。
3. 「科学测验」一开始就是已发布示例。「科学草稿」在发布前，家长和学生都看不到。

## 通知和留言

1. `t1` 发布「科学实验」的成绩后，用 `p1` 打开「通知」。能看到 `grade_released` 站内通知。静态演示还会列出一封演示邮件，只有标题和链接，没有分数正文。
2. 在任务页写一条留言。再用 `t1` 打开「留言」，未读的对话排在前面。打开后可以回复。
3. 「通知设置」可以改成每周、每天或关闭，并填写免打扰时间。
